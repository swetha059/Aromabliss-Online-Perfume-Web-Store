🌸 Aromabliss Online Perfume Web Store

Aromabliss is a modern and responsive online perfume shopping web application developed using React JS.

✨ Features

- 🔐 User Login System
- 🛍️ Product Listing Page
- ❤️ Wishlist Functionality
- 🛒 Shopping Cart
- 💳 Payment Page
- 📱 Responsive Design
- 🎨 Attractive UI

🚀 Technologies Used

- React JS
- JavaScript
- HTML5
- CSS3

📂 Project Structure

- Components
- Pages
- Product Cards
- Navbar
- Cart & Wishlist
- Payment Module

🎯 Project Objective

The main objective of this project is to provide users with a smooth and user-friendly online perfume shopping experience.
